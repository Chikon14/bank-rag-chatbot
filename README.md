# 🏦 Bank RAG Chatbot

Чат-бот для банковских консультаций на основе технологии RAG (Retrieval-Augmented Generation).

## 🎯 Что делает проект

Бот отвечает на вопросы клиентов банка строго на основе официальных документов — без выдумок и галлюцинаций. Если информации нет в базе знаний, бот честно об этом сообщает.

## 🛠️ Технологии

- **Python** — основной язык
- **Groq API + LLaMA 3.3 70B** — языковая модель
- **RAG** — ответы только на основе документов банка

## 💡 Как работает

1. Загружается документ с условиями кредитования банка
2. Клиент задаёт вопрос в чате
3. Документ + вопрос передаются в LLM
4. Модель отвечает строго по документу
